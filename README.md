# DOMIHOOD · 浮空小岛

DOMIHOOD 正在从旧版粉丝社区转向一个可以持续成长的童话小岛。

## 当前已实现

- 浮空岛首页视觉与交互原型。
- 鼠标 / 触控拖动旋转岛屿视角，支持缩放与重置。
- 粉丝广场、回忆咖啡馆、私人小屋的探索入口。
- 私人小屋 3D 房间、三种房间主题、家具添加 / 移除 / 网格摆放与碰撞检查。
- 小屋本地保存；账号后端配置完成后，可读取和保存账号专属云端布局。
- 昵称 + 密码注册 / 登录 / 退出与服务端会话 API（需完成 Supabase 迁移、EdgeOne 环境变量配置并重新部署后启用）。
- 访客模式（昵称与本地布置只保存在当前设备）。
- 手机与桌面端适配。

## 本地开发

```bash
npm install
npm run dev
```

## 构建检查

```bash
npm run build
```

## 部署前检查

参考 [昵称密码账号与小屋云端同步配置说明](docs/nickname-password-auth.md)。账号注册和云端保存依赖 Supabase 数据表、EdgeOne 服务器端环境变量及兼容的 Node.js Route Handlers 运行环境；GitHub 构建成功不等于线上服务已完成验证。

## 后续规划

1. 继续打磨 3D 房间表现、家具模型和移动端操作体验。
2. 完成账号与云端同步的真实部署验证，再完善账号安全能力。
3. 逐步开发岛民互动、回忆整理与拍照机等独立模块。

> 粉丝广场、回忆咖啡馆的互动功能仍属于后续规划，当前入口是原型展示，并不代表在线多人功能已经实现。
